# Lakshmi Chaturya – Portfolio Website

A personal professional portfolio website built as part of the **Future Interns Full Stack Web Development Task 1**.

## 📁 Project Structure

```
my-portfolio/
├── index.html       → Main HTML structure
├── style.css        → All styling and layout
├── script.js        → Interactivity (nav, animations, form)
├── images/          → Add your photo here (save as profile.jpg)
└── README.md        → This file
```

## 🚀 How to Run Locally

1. Open the `my-portfolio` folder in VS Code
2. Install the **Live Server** extension
3. Right click `index.html` → **Open with Live Server**

## 🌐 How to Deploy on GitHub Pages

1. Push this folder to a public GitHub repository
2. Go to **Settings → Pages**
3. Select `main` branch → Save
4. Your site will be live at `https://yourusername.github.io/repository-name`

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- Vanilla JavaScript (Intersection Observer, animations)

## ✏️ How to Customize

- **Your photo**: Save your photo as `profile.jpg` inside the `images/` folder
- **Project links**: Replace `href="#"` in project cards with your real GitHub links
- **Contact**: Update email, phone, LinkedIn in `index.html`
